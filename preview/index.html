HinterOS

A NixOS-based Linux distribution with a controller interface for gaming and media.

Download 1.0.0 Try the launcher

Features

Controller only

Use a controller for all of the system: the installer, Home, Store and Settings. The Guide button always opens Home.

Profiles for each person

Each person has a profile with its own apps, Steam library, settings and PIN. A guest profile is deleted when the computer restarts.

Sandboxed apps

Each app can see only its own files. An app can use the microphone, Downloads, the controller or the local network only with your permission.

Curated store and Steam

Install apps and games from a curated store. Your Steam games show in Games, next to the other games.

Jellyfin and Plex

Watch media with the Jellyfin and Plex apps. You can also run a Jellyfin or Plex Media Server on the same computer.

Pointer and on-screen keyboard

In web apps such as Firefox, the right stick moves a pointer. Hold Guide and push Y to open the on-screen keyboard.

Technical stack

NixOS

HinterOS is a layer of NixOS modules and an overlay on nixpkgs. It is not a fork.

  • It follows nixos-unstable. Each channel (stable, beta and main) is one locked flake.
  • One file, /etc/hinteros/state.json, keeps all the settings of a box.
  • Each update is a signed commit. The box verifies the signature before it rebuilds.
  • If the launcher or the daemon does not start, the box starts the previous generation.

Daemon

Two Rust services control the system. The launcher contains no system logic.

  • hinteros-session runs as the user. It controls input, apps, audio, display, Wi-Fi and Bluetooth.
  • hinteros-system runs as its own account, not as root. It controls settings, updates, rollback and app installs.
  • The services use JSON-RPC on Unix sockets. polkit authorizes each change, and the journal records it.

Input

InputPlumber takes the physical controllers and gives virtual controllers to the system.

  • When the launcher is in focus, it gets all input. When an app is in focus, the input goes directly to the app.
  • The Guide button always opens Home. On a keyboard, use Ctrl+Super+D.
  • Hold Guide and push Y to open the on-screen keyboard.
  • In TV web apps, the right stick moves a pointer and RT clicks.

Session

gamescope runs the session. A Flutter launcher is the home app.

  • Each app has its own X display. An app cannot read the text that you type in the launcher, for example a PIN.
  • The launcher shows your Steam library and starts Steam games through Steam.
  • PipeWire controls audio. HDMI is the default output.
  • If you do not confirm a new resolution in 15 seconds, the display goes back to the previous one.

Sandbox

Each app from the Store runs in a Bubblewrap sandbox with a system call filter.

  • An app has its own home folder, the GPU and its own display. It cannot see other apps or your files.
  • Apps can ask for four permissions: controller, microphone, Downloads and local network. Each profile can deny each permission.
  • Apps are Nix packages from the HinterOS catalog. Each profile installs its own apps without a system rebuild.
  • Steam and Steam games do not run in the sandbox.
