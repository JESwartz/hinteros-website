Steam

Each profile has its own Steam. A profile has its own Steam account, its own games and its own game saves.

Install Steam

  1. Select Games at the top of the screen. If Steam is not installed, select Install Steam. You can also install Steam from the Store.

  2. Read the install dialog. Steam has the permission Full profile access, because it cannot run in the sandbox.

  3. Read the Steam Subscriber Agreement and select Accept and install.

Steam needs approximately 1 GB. Each profile that uses Steam must install it.

If the admin profile selected Steam as a starter app, Steam is already installed in new profiles. Steam then shows its terms the first time that you open it.

Sign in

  1. Select Steam in Apps or on Home. HinterOS opens Steam in Big Picture mode.

  2. Sign in to your Steam account in Steam.

The first start takes more time, because Steam updates itself. The screen shows Steam is updating itself. This can take a few minutes.

Big Picture and HinterOS

Use Big Picture for the Steam store, downloads and the Steam settings.

HinterOS shows the games that are installed in Steam:

  • Games shows your Steam games with their covers.

  • Home shows the games in a row.

  • Continue on Home shows the games and apps that run now.

Games that you add to Steam as non-Steam games also show in Games. Hidden games and Steam tools, for example Proton, do not show.

A game that is not ready shows a label, for example Updating, Installing or Update required. For Update required, open Steam to update the game.

Play a game

Select a game in Games or on Home. HinterOS starts the game through Steam.

Push Guide to go back to Home. The game continues to run. To go back to the game, select it in Continue.

If Steam shows a message while you are in HinterOS, a banner shows Steam needs your attention. Select Open Steam or push X.

The Steam menu

Hold Guide for half a second while Steam or a Steam game is on the screen. Steam shows its menu:

  • In a game, Steam shows its in-game menu.

  • In Big Picture, Steam shows its main menu. The Steam controller settings are in this menu.

A short push on Guide goes to Home.

Close a game

Use the menu of the game to save and quit, if the game has one.

To close a game from HinterOS:

  1. Go to the game in Continue on Home, or in Games.

  2. Push Y.

  3. Select Close.

The game can lose unsaved progress. If the game does not stop in 5 seconds, HinterOS stops it.

If Steam does not respond, open the Steam page in the Store and select Force stop. Steam and all its games stop immediately, and unsaved progress is lost.

Steam and other parts of HinterOS

  • When you change profile, HinterOS closes Steam and its games. For more information, refer to Profiles.

  • Steam and Steam games do not count in Settings → System → Apps open at once.

  • Steam can use all data and devices of your profile. For more information, refer to Apps and the Store.

If you remove Steam and delete its data, HinterOS deletes all games that this profile installed through Steam. You must download them again.
