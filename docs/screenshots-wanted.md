# Screenshots for HinterOS.org

The website's home page is getting a tour: one screenshot per screen, each next to a short
explanation. Please capture these from a real HinterOS box running the 1.0.0 candidate.

## Capture settings

- Size: 1920x1080, native gamescope output with no scaling, saved as lossless PNG.
- Leave out overlays and banners: no update banner, FPS overlay, toasts or screen saver.
- Use the default theme and the stock layout.
- Fill the screens with real content. Use real installed apps and games with their real icons and
  artwork, so that no tile shows a letter placeholder.
- Use believable names for the profiles, such as "Sam" or "Alex", not "test" or "user1". Include
  nothing personal: no real names, emails, Wi-Fi network names, IP addresses or serial numbers.
- Set the clock to a sensible evening time, such as 19:40.
- Leave the focus ring where it's described below. The ring shows readers how the controller
  moves around.

## Shots

| File | Screen | What it should show |
|---|---|---|
| `home.png` | Home tab | The Continue row with two or three recent items, plus Apps and Games rows. Focus on the first Continue item. This replaces the current hero image, which came from the browser demo. |
| `games.png` | Games tab | Several games, both Steam and non-Steam, with cover art. Focus on a game. Party games and older titles fit the site's pitch. |
| `apps.png` | Apps tab | The streaming apps (Jellyfin, Plex, YouTube/VacuumTube, Firefox), with focus on Jellyfin. |
| `store.png` | Store | The curated store's main list, with focus on an app that isn't installed yet. |
| `store-app.png` | A Store app page | One app's page with its Install button and its permissions (network, microphone and so on) visible. This illustrates the sandboxing feature. |
| `profiles.png` | Profile picker | Two to four profiles with avatars, one of them PIN-protected if the picker shows that. |
| `settings.png` | Settings | The top level of Settings, with focus on the first section. |
| `pointer.png` | An app using the stick pointer | For example, Firefox on a web page with the pointer visible over a link. |
| `keyboard.png` | On-screen keyboard | The keyboard open over a text field, such as a search box, with a few letters typed. |
| `split-screen.png` | Split screen *(only if it ships in 1.0.0)* | Two profiles playing side by side. Skip this one if split screen isn't in 1.0.0, and tell me so that the site stops claiming it. |
| `server.png` | Media server settings *(optional)* | The screen where Jellyfin or Plex Media Server is turned on. |

## Delivery

Put the PNGs in one folder and tell me the path, plus anything that differs from the list above:
a screen that doesn't exist, a different name, or a feature that isn't in 1.0.0. I'll convert them
to WebP and resize them for the site.
